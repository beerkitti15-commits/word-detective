# Word Detective – นักสืบคำศัพท์

เกมคำศัพท์ 3 ภารกิจ + หลังบ้านสำหรับครู (ใส่คำศัพท์เอง / ให้ AI สร้าง passage)

## ตั้งค่าบน Railway (Variables)
| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `ADMIN_PASSWORD` | รหัสผ่านเข้าหน้าหลังบ้าน `/admin` (ต้องตั้ง ไม่เช่นนั้นหลังบ้านจะปิด) |
| `ANTHROPIC_API_KEY` | คีย์ Anthropic สำหรับให้ AI สร้าง passage |
| `ANTHROPIC_MODEL` | (ไม่บังคับ) ชื่อโมเดล ค่าเริ่มต้น `claude-sonnet-5-5` |
| `DATA_DIR` | (ไม่บังคับ) โฟลเดอร์เก็บข้อมูล เช่น `/data` ที่เมานต์ Volume ไว้ |

> ข้อมูลชุดคำศัพท์เก็บเป็นไฟล์ `sets.json` ใน `DATA_DIR` – บน Railway ให้เพิ่ม **Volume** แล้วตั้ง `DATA_DIR` ไปที่ path ของ Volume ไม่เช่นนั้นข้อมูลจะหายเมื่อดีพลอยใหม่

## วิธีใช้
1. เปิด `/admin` ใส่รหัสผ่าน → สร้างชุดคำศัพท์ (`word, คำแปลไทย, วิชา` วิชา = M/S/SS/L) อย่างน้อย 12 คำ
2. กด ✨ ให้ AI สร้าง Passage → ตรวจ/แก้ไขได้
3. นักเรียนเปิดหน้าเกม เลือกชุดคำศัพท์ตอนลงทะเบียน

รันในเครื่อง: `ADMIN_PASSWORD=xxx ANTHROPIC_API_KEY=sk-... node server.js`
